# Driftbox Desktop - Installation Guide

## Quick Start

1. **Install Node.js** (if not already installed)
   - Download from: https://nodejs.org
   - Choose the LTS version

2. **Extract this folder** anywhere on your computer

3. **Double-click `start-driftbox.sh`** to launch Driftbox
   - On first run, it will install dependencies (takes 1-2 minutes)
   - Subsequent launches are instant

## What You Get

- Full desktop IDE with GitHub integration
- Local file operations
- Terraform validation and formatting
- AI-powered infrastructure analysis

## Troubleshooting

**Permission denied error?**
```bash
chmod +x start-driftbox.sh
./start-driftbox.sh
```

**Can't find Node.js?**
- Make sure Node.js is installed
- Restart your terminal after installing Node.js
