# 🚀 Driftbox Desktop

**AI-Powered Infrastructure IDE for Windows**

## Quick Start

1. **Install Node.js** (if not already installed)
   - Download from: https://nodejs.org
   - Choose the LTS (Long Term Support) version
   - Run the installer

2. **Launch Driftbox**
   - Double-click `Driftbox.bat`
   - On first run, it will install dependencies (takes 1-2 minutes)
   - The app will open automatically

3. **That's it!**
   - Sign in with GitHub
   - Start managing your infrastructure

## Features

✅ Full IDE with Monaco Editor

✅ AI-Powered Infrastructure Analysis
✅ Drift Detection

## System Requirements

- Windows 10 or later
- Node.js 18+ (LTS recommended)
- 4GB RAM minimum
- Internet connection for GitHub OAuth

## Troubleshooting

**If Driftbox.bat doesn't run:**
- Right-click on Driftbox.bat and select "Run as administrator"
- Make sure Node.js is installed and accessible from Command Prompt
- Check that you have extracted all files from the ZIP archive

**If you see "node is not recognized":**
- Node.js may not be in your PATH
- Reinstall Node.js and make sure to check "Add to PATH" during installation
- Restart your computer after installing Node.js
